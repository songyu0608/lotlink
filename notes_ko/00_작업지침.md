# LotLink 작업 지침 해설 (한국어)

**지침의 정본은 리포지토리 루트의 `CLAUDE.md`(일본어)다.** 이 문서는 그 내용을 한국어로 풀어 쓴 해설이며, 내용이 다르면 `CLAUDE.md`를 따른다.

## 요점

| 항목 | 내용 |
|---|---|
| 역할 | 사용자: 가상 고객 겸 PM(판단·승인). Claude: 초안 작성, 선택지 제시, 용어 설명 |
| 언어 | 성과물·커밋·PR은 일본어. 대화와 해설은 한국어 |
| 진행 | 한 번에 한 스텝. 초안 → 검토 → 확정. 확정 전에 다음 스텝으로 넘어가지 않는다 |
| 문서 | `docs/00_共通/02_ドキュメント規約.md`를 따른다. ID는 재사용하지 않는다 |
| 기록 | 스텝 확정 시 `01_진행기록_결정사항.md`와 `02_용어집.md`를 갱신한다 |
| Git | `main`에 직접 푸시하지 않는다. 스텝별 브랜치 → PR → 사용자가 머지하면 확정 |
| 보관 | GitHub가 정본. Claude 프로젝트는 머지 후 반영하는 사본. PC 폴더는 동기화하지 않는다 |

## 왜 이렇게 정했나

- **PR 방식**: "초안 → 검토 → 확정" 사이클과 그대로 대응하고, 포트폴리오에 プルリクエスト와 レビュー 이력이 남는다.
- **GitHub 정본**: 어느 기기에서든 같은 Claude 계정이면 작업할 수 있다. PC 폴더는 그 PC가 켜져 있고 연결된 대화에서만 쓸 수 있어 제외했다.
- **noreply 주소**: 공개 리포지토리의 커밋 이력에 개인 이메일이 남지 않게 하기 위함.

## 새 대화에서 이어갈 때

1. `lotlink` 리포지토리를 연결한다.
2. `notes_ko/01_진행기록_결정사항.md`의 "다음 할 일"을 확인한다.

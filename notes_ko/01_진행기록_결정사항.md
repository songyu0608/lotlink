## 2. 要件定義 성과물 조정 (참고 글 반영)

참고: https://pm-rasinban.com/rd-write

**추가**
- 狙い(기대 효과)
- 業務機能構成表
- システム方式(AWS 構成 개요)
- 画面遷移図
- 概念ER図 + テーブル一覧
- 外部システム関連図

**생략**
- ハードウェア構成図 (클라우드 구성이라 システム方式로 대체)
- 帳票レイアウト (帳票一覧만 작성)
- 業務処理定義 상세 (業務フロー図로 대체)
- 外部インターフェース定義書 (基本設計에서 작성)

**정정한 내용**
- ER図와 システム構成図는 基本設計에서만 만드는 것이 아니다. 要件定義에서 주요 테이블·개요 수준으로 먼저 작성하고, 設計에서 상세화한다.
- 非機能要件 6번째 분류의 정식 명칭은 「システム環境・エコロジー」.

## 3. 기술 구성 (안, 基本設計에서 확정)

- API: FastAPI + PostgreSQL
- 배치: Lambda + EventBridge
- 아카이브: S3 → Glacier
- CI/CD: GitHub Actions + pytest
- IaC: Terraform 또는 AWS CDK (여유 있을 때)
- 프론트엔드: 미정
- 비용 주의: RDS는 과금될 수 있으므로 개발은 로컬 Docker PostgreSQL, AWS는 데모 시에만 사용. 무료 범위는 본인 계정에서 확인 필요.

# LotLink 용어집 (일본어 → 한국어 설명)

스텝을 진행하면서 계속 추가한다. 성과물용 용어집(`docs/01_要件定義/99_用語集.md`)과는 별개다.

## 1. 工程 (개발 단계)

| 용어 | 읽기 | 설명 |
|---|---|---|
| 案件 | あんけん | 프로젝트 건. SES 등에서 참가할 일감 단위 |
| 工程 | こうてい | 개발 단계 |
| 上流工程 / 下流工程 | じょうりゅう / かりゅう | 要件定義·設計 쪽 / 구현·테스트 쪽 |

| 基本設計（外部設計） | きほんせっけい | 외부에서 보이는 사양을 정하는 설계 |
| 詳細設計（内部設計） | しょうさいせっけい | 내부 처리 로직을 정하는 설계 |
| 実装（製造） | じっそう（せいぞう） | 코딩. 현장에서는 製造라고도 부른다 |

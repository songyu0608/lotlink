# LotLink

化粧品メーカー（架空）向けの受注・在庫管理システムです。
要件定義から開発・テストまでの各工程を一通り実施し、工程ごとの成果物を残すことを目的とした個人開発のポートフォリオです。

## 現在の状況

要件定義を進めています（ステップ2「現行業務と課題」まで作成）。ソースコードはまだありません。

## 概要

- 自社ECサイトとAmazonの複数チャネルから受注を取り込み、在庫引当を行う
- ロット・使用期限を考慮した在庫管理
- 日次集計バッチと古いデータのアーカイブ

決済はモック、Amazon連携は注文CSVの取込で代替します。詳細は [プロジェクト概要](docs/00_共通/01_プロジェクト概要.md) を参照してください。
